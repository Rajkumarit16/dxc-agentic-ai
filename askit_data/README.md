# AskIT data (Orbit Corp IT Helpdesk)

| File | What |
|---|---|
| `kb/` | 20 IT policy & how-to articles (Markdown) — AskIT's knowledge base |
| `tickets.csv` | 100 helpdesk tickets. `category`, `priority`, `sentiment` are the **human labels** — use them to check AskIT's answers |
| `users.csv` | 30 employees. `vip = yes` → always handled by a human (see KB-017, KB-018) |

All names, emails and URLs are fictional.
