# Installing Software

**Category:** Software  
**ID:** KB-008

Approved software is self-service from the **Orbit Software Center** — no ticket needed.
Software not in the catalogue needs a Software Request with a business reason; Security reviews it within 5 working days.
Admin rights are never granted permanently. Temporary admin (4 hours) requires manager approval.
Pirated or personal-licence software is not allowed on Orbit devices.
